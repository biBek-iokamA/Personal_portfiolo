# Personal Portfolio

A personal portfolio website created and developed by me to showcase my skills, projects, experience, and technical journey.

## 🚀 Features

* Modern and responsive design
* Personal introduction and profile
* Skills and technologies
* Project showcase
* Contact section
* Responsive layout for desktop, tablet, and mobile
* Clean and user-friendly interface

## 🛠️ Technologies Used

This project is built with:

* React
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui
